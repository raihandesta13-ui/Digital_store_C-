# 🛒 Toko Mak Lampir - C++ Console Game

A hilarious text-based grocery store simulation game built in C++, featuring inventory management, employee systems, and the legendary Toko Mak Lampir (Ngawi Branch)!

## ✨ Features
* **Employee Recruitment System**: Choose to remain unemployed or apply for a store position with humorous requirements (e.g., UGM S3 Economics graduate!).
* **Price Management**: Employees can adjust product prices (Cheetos & Soda) in real-time.
* **Sales & Inventory System**: Check stock availability, purchase items with automatic inventory validation, and calculate total payments.
* **Error Handling**: Protected against invalid inputs to prevent the game from crashing or entering infinite loops.

## 🚀 How to Run (Compile & Run)
1. Make sure you have a C++ compiler (like MinGW/GCC) installed on your computer.
2. Download or clone this repository.
